# Index Explorer：市场热点指数数据页

风格包 `index-explorer` 的示例：一页自包含的中文数据探索页（`index.html`，无构建、无依赖，单文件内联样式与脚本），题为「市场热点指数」，给量化交易项目用。象牙白纸面、近黑墨色；名称、标题和数字是衬线，标签、图例、图注是中性无衬线，排名和数值是等宽字体；一套四级色阶（默认红涨绿跌：由浅到深的四级红，上涨红、下跌绿；可切换为绿涨红跌，即原来的四级绿）；一个强调色只用于标记（下跌的三角、折线端点、第三条线）。深色主题随系统（`prefers-color-scheme`）。

内容是占位：**所有数字都在页面里由种子生成（`rng(20261121)`），页面各处标注“示例数据”**，不是行情，也不构成任何建议。地图是 31 个省级单位的方格地图（一张 8 x 8 的表，每格一个字），不是地理文件，不带任何边界或底图。语法量自两个公开的数据探索页（私下用 Chrome 量计算样式，不进仓库），只带走数字和规则，见 [style.json](../../skill/tools/template-bank/styles/index-explorer/style.json)。借语法，不借素材：不使用任何机构名、标志、字标、地图、数据和原版专有字体。

## 打开

```bash
cd examples/index-explorer-kit
python3 -m http.server 8850      # 或直接双击 index.html
# http://127.0.0.1:8850/index.html
```

字体通过 Google Fonts 加载 Source Serif 4、Inter、JetBrains Mono、Noto Serif SC、Noto Sans SC（均为 SIL OFL）；离线时落到系统衬线与无衬线，版式不变。

## 用自己的数据

展开页面底部的“用你自己的 CSV 驱动页面”，贴入 CSV（或选文件），点“应用 CSV”：

```csv
date,province,sector,value
2026-11-01,江苏,半导体,1.32
2026-11-01,江苏,新能源,0.97
```

- 表头必须是 `date,province,sector,value` 四列；`date` 写 `YYYY-MM-DD`，`value` 是大于 0 的数（相对预期的倍数，1.0 为预期，不要百分号）。
- `province` 用单字或全名（如 江 或 江苏），不认识的省份会被跳过并在状态行列出；`sector` 随文件出现的板块自动生成筛选项。
- 周期最长取近 30 日，文件里的天数不足时取全部；表头不对或没有可用的行会提示，页面不变。数据只在浏览器里解析，不上传、不保存。
- “载入示例到文本框”填入一份演示数据；“恢复示例数据”回到生成的示例数据。来源标签在 SAMPLE DATA 与 YOUR CSV 之间切换。

## 红涨绿跌 / 绿涨红跌

页面顶栏右侧有一个小的分段开关：**红涨绿跌**（默认，国内市场习惯）和**绿涨红跌**（国际习惯）。切换时地图、图例、排名条形、折线、表格里的色点、周变化三角和统计卡三角同步换色，没有重绘；选择记在 `localStorage`（键 `idx-conv`，读写都包在 `try/catch` 里，隐私模式下只在本次访问有效）。链接带 `?conv=intl` 或 `?conv=cn` 时以链接为准，方便截图和检查。

- 红涨绿跌：色阶 `#F6D4CC #EE9E8C #E07A63 #D75A44`（由浅到深，起步到领先），上涨为红三角、下跌为绿三角（`#388F76`）；统计卡的迷你折线、面积和端点跟随涨跌方向取色。最深一级与瓦片名称的固定深墨色是 4.8:1。
- 绿涨红跌：原来的四级绿，上涨绿三角、下跌珊瑚三角；迷你折线一直是绿色，端点珊瑚色。
- 模板里对应的是 `--param convention=cn|intl`（默认 `intl`，保持量出来的绿色谱系），页面默认 `cn`。

## 动效

- 方格地图的格子随进入视口淡入并上色；排名和指数条的条形生长；统计卡数字从 0 数到目标值；折线用 `pathLength` 与 `stroke-dashoffset` 自己画出来。
- 改变筛选时，地图着色、排名、折线和表格平滑过渡。
- `prefers-reduced-motion` 下全部关闭（CSS 里一个 reduce 块，脚本里用 `matchMedia` 判断），页面一开始就是终态。

## 改它

- 颜色、字体、间距在 `:root` 的变量里；深色值写在同一个 `light-dark()` 里；红涨绿跌只是 `:root[data-conv=cn]` 里五个变量（`--s1`…`--s4` 与 `--coral`）的覆盖，页面其余部分都读这些变量。
- 种子在脚本顶部（`rng(20261121)`），省份表 `PROV`、板块表 `SECT0` 也在那里；改它们换内容。
- 瓦片上的名称固定用深墨色（深绿上 4.7:1，深红上 4.8:1），主题切换和涨跌配色都不改它；强调色（珊瑚或绿）只用于标记，不用于小字。

## 检查

页面通过 `template check` 的浏览器部分（先用页高量一次，页高随宽度变化）。检查本身会冻结 CSS 过渡和动画；两种配色在浅色与深色下都已检查，宽 1440 和 390 各 0 条发现；仓库测试还用 `--force-prefers-reduced-motion` 启动 Chrome，使脚本动效停在终态、结果确定：

```bash
node skill/scripts/designer-pipeline.cjs template check examples/index-explorer-kit/index.html --browser --size 1440x5451
node skill/scripts/designer-pipeline.cjs template check examples/index-explorer-kit/index.html --browser --size 390x7280
```

适配：检查对每个文字单元要截好几次图，所以文字按小块分组（`data-chk`）：每个方格名称是一个单元（量在它自己的瓦片上，不跨缝隙和空格），坐标轴标签是一个单元，排名每列四叠，“怎么读”和脚注每段一个单元；`data-chk` 不嵌套（外层只是容器，自己的文字不会被量）。折叠的 `<details>` 内容会在过时的位置被量到画布外，所以 CSV 面板的内容在展开时才从 `<template>` 注入。结构与约束通过，不等于视觉验收；视觉由主人看图决定。
